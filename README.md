# BONTOT WEATHER

**Know the Sky. Own Your Day.**

Repository untuk pengembangan aplikasi BONTOT WEATHER.

## Status

Source React/TypeScript awal diunduh dari Gemini dan sedang diintegrasikan ke workspace lokal `C:\Projects\BONTOT WEATHER`. Simpan seluruh source, konfigurasi, dokumentasi, tes, dan perubahan fitur di repository ini.

## Prinsip pengembangan

- Pertahankan UI, branding, fitur, dan perilaku yang sudah ada kecuali perubahan memang diperlukan untuk memperbaiki bug.
- Jangan commit dependency hasil instalasi (`node_modules`), hasil build (`dist`/`build`), file log, atau rahasia (`.env`).
- Jangan menyimpan API token, password, atau credential ke Git.
- Jalankan build dan tes yang tersedia sebelum menyatakan perubahan terverifikasi; dokumentasikan hasil aktual.
- Gunakan commit kecil dengan pesan jelas, dan jangan menimpa perubahan lokal yang belum disimpan.

## Sumber cuaca

Aplikasi menggunakan layanan Open-Meteo untuk prakiraan cuaca, kualitas udara, dan geocoding. Periksa kode dan dokumentasi implementasi sebelum membuat klaim mengenai ketersediaan atau cakupan fitur.
